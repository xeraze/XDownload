## ✨ How it works

<div align="center">

```
   paste a link          pick a format           get the file
 ───────────────►  🎵 Audio  /  🎬 Video  ───────────────►  📁 done
                                       ▲
                            480p · 720p · 1080p
```

</div>

1. Open the bot and press **Start**
2. Send a link — any supported platform
3. Choose **🎵 Audio (mp3)** or **🎬 Video (mp4)**
4. For video, pick quality: **480p / 720p / 1080p**
5. The file lands in the chat — save or forward it

> Spotify & SoundCloud are audio-only — the bot knows and shows only the audio button.

## ⚠️ Notes

- **Personal use only.** Downloading from YouTube or Spotify may violate their terms of service; Telegram can block public music bots.
- Private, age-restricted, or region-locked media may fail.
- Public Bot API caps files at ~50 MB; a local Bot API server raises the limit.
- The bot stores nothing about you — see the [Privacy Policy](docs/privacy-policy.md).
